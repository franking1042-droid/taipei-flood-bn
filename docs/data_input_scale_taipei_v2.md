# 資料輸入尺度清單 — taipei_v2_village（士林、北投 93 里）

更新：2026-10-26。回答一個問題：**BN 的每一項輸入，資料原本是什麼尺度、我們用到什麼尺度、怎麼落到里。**

- v1（`taipei_v1`）的空間單元是 2 區；v2（`taipei_v2_village`）換成 93 里（士林 51、北投 42，民政局里界圖）。
- 模型本體 `bn_engine/bn_v0220.pkl`、CPT、切點、規則完全不動；節點集合與臺南 v0188 相同（16 個 status-quo evidence ＋ 8 個 FloodZone E 節點 ＋ H2 錨定）。
- 10/22 會議定的規則：有里級就用里級；只有區級的，同一區內每個里給同一個值；空間呈現一律用里。

## 1. 解析度類別

| 類別 | 意思 |
|---|---|
| 里級原生 | 資料本來就以里為單位發布 |
| 面資料裁切到里 | 多邊形圖資（潛勢圖、土地利用）以里界裁切後逐里加總面積 |
| 點位→里 | 點資料（抽水站、收容所、LULC 代表點）依落點或服務範圍歸到里 |
| 區級複製 | 只有區級統計，同區各里同值 |
| 市級常數 | 全市同值的知識法則 |
| 情境 | 推論時指定 |

### 2.3 潛勢區暴露 E 節點（8 節點，24h350／24h500 兩情境）

共同方法：LULC 建築（05）、農地（01）圖斑的代表點 → 落在哪個里、是否在潛勢區內 → 里的「潛勢區內建築面積比」→ 里人口分層乘上去（人口沿建築分布，同臺南 v0213）。
離散化：沿 v1，用臺南 37 區各級邊界中點的**絕對切點**；等級語意＝「放進臺南 37 區分布屬第幾級」。計數型節點在里尺度數值天生較小，多數里落在 very_low，這是真實的「單位變小、絕對暴露量變小」。`E_node_levels_village_v2.csv` 另附 `level_q93`（93 里情境內相對分級：0 暴露→1，非 0 依四分位→2–5）供敏感度比較，推論未用。

## 6. 結果一眼看（H1＝超大豪雨＋E 24h500，錨定，等權）

- 64 里完全沒有潛勢區暴露，O_total 期望值停在模型底值 0.292；有暴露的 29 里才有區別。
- 前十：吉慶 1.62、立賢 1.56、八仙 1.54、立農 1.47、一德 1.29、尊賢 1.24、大同 1.19、福華 1.15、豐年 1.08、福安 1.07（接著富洲 1.06、明勝 1.03、洲美 0.98）。前四里放進臺南 37 區都排第 1。
- 熱點是關渡平原東側的石牌一帶（吉慶、立賢、立農、尊賢、八仙）與社子島（福安、富洲），北士科周邊（洲美、建民、福華、後港）居中。
- 區級 vs 里級不能直接比大小：v1 區級 O_total 北投 1.148／士林 0.756，v2 里級人口加權均值北投 0.60／士林 0.47。E 節點是絕對暴露量，整區合計一定比單一里大，所以區級值偏高是尺度效應，不是模型改變。
- 三軸政策 do(NbS=高, SMC=高, DRNS=高)：RR_total 均值 0.010、最大 0.115（一德里）；無暴露的里為 0；少數里微負（與 v1、臺南相同的上游 CPT 反置洩漏）。
