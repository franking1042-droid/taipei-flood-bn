# 臺北（士林、北投）Evidence 對照表 — taipei_v1

目的：把臺南 BN v0.22.0 **原樣**（pkl、CPT、節點、狀態都不動）套到臺北市士林區、北投區，只換三份輸入。本表逐節點記錄臺北的原始值、採用的狀態、沿用的臺南切點／規則，以及資料來源，供審查「是否可比」。

資料來源代號：`DT` = `中鋼計畫\團隊內部討論紀錄\中綱BN建構\Data\Data_taipei\`（README 內有每個檔的出處）；repo 內 `data/taipei/` 是這些檔的副本。

## 4. 不能直接可比的地方（審查時請先看這段）

1. **空間單位**：臺南 37 區（平均 61 km²）vs 士林 62 km²／北投 57 km²，面積量級一致，但臺北兩區一半以上是山區，所有「占區面積」指標（不透水、NbS、綠基盤、水利用地）都被山區稀釋。
2. **LP.river_corridor_designation** 規則只看水利利用地占比，臺北的河濱公園、堤防、疏散門系統沒有被這個節點看見，兩區都落在「僅河道用地」。
3. **DR.StructuralMeasures_Coverage** 用臺南五分位，臺北任何一區都是「高」，此節點在臺北沒有鑑別力。
4. **E 節點用臺南邊界**：等級語意是「放在臺南 37 區的分布中屬於第幾級」，不是臺北內部的相對位置。
5. **VS 四節點切點**是從 v0151 輸出反推的（文件版與實作版不一致，臺南端 Mike 尚未裁定）。
6. **人口分層年期**：年齡結構用 112 年 1 月各里資料，乘上 114 年底總人口；獨居、身障為 114 年底。
7. 模型本身的已知問題（SMC→DSE、NbS→RC CPT 方向反置、降雨幅度傳不到 O_total 等，見臺南 v0220 close report 與 skg/INDEX）在移植版**原樣存在**。
